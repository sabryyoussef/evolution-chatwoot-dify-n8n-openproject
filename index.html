Production path

A message on WhatsApp is captured, analyzed, and either becomes an OpenProject work package or a short Arabic reply.

Evolution — WhatsApp gateway

Evolution is the phone connection, not the inbox. Use it to scan QR, check instance status, and set webhooks. Instance: sabry min.

Open Evolution Manager API docs

Open this UI when

Reconnect WhatsApp after the phone logged out.

Confirm the instance is connected before blaming Chatwoot.

Point the webhook at n8n Evolution WhatsApp Webhook.

Chatwoot — the inbox

Where humans and automation see the same conversation. Account 2, inbox 2. Labels such as dev-needed, cyclex, ai-create-wp drive n8n.

Open Chatwoot

Open this UI when

Read a client thread, add a label, assign an agent.

Check why n8n did not fire (missing label or inbox).

Configure the WhatsApp inbox webhook into n8n.

n8n — the orchestrator

n8n is the only layer allowed to execute. It receives Chatwoot webhooks, calls Dify, then creates OpenProject work packages and optionally replies on WhatsApp.

Open n8n chatwoot-ai-analysis
Do not fire production webhooks in a demo. Opening the editor is safe. Triggering the workflow creates real work packages.

Dify — AI understanding

Dify classifies the message, picks the project, extracts OpenProject fields, and drafts a short Arabic reply. It does not create tasks. n8n consumes its JSON.

Open Dify Studio Platform Copilot

Open this UI when

Tune triage prompts, knowledge retrieval, or JSON schema.

Preview a sample WhatsApp message before n8n runs it live.

OpenProject — source of truth

Every accepted bug, feature, and follow-up lives here. Unmapped WhatsApp work lands in WhatsApp Queue (project 14).

Open OpenProject

Odoo — ERP and clinic

Business operations live here: Pet Spot production, test, Sabry site, and Haram POS. Dify may use Odoo for ERP context; it does not replace OpenProject for tasks.

Open Odoo (prod) Test Sabry site Haram POS

Nextcloud — files and knowledge

Project documents, group-project map, and files Dify / Cursor can read. This is the document store, not the inbox and not the task board.

Open Nextcloud

Open WebUI — local AI chat

Chat against Ollama on this server. Use it for local experiments. Production WhatsApp triage stays on Dify + n8n.

Open Open WebUI

OpenClaw — agent console

Control UI for the OpenClaw gateway. Keep it off the same WhatsApp number as Evolution. Dual login on one phone breaks the inbox path.

Open OpenClaw
